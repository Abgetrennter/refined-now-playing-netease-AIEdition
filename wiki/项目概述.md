# 项目概述

> 版本: 2.19.5  
> 最后更新时间: 2025-12-01

## 1. 项目背景

**Refined Now Playing (AI Edition)** 是一个基于 BetterNCM 平台的网易云音乐客户端插件。该项目旨在彻底重构和美化网易云音乐的"正在播放"页面，提供现代化、沉浸式且高度可定制的视觉体验。

原版客户端的播放界面功能较为单一，缺乏视觉吸引力。本项目通过注入自定义的 CSS 和 JavaScript，引入了 Material You 设计语言、动态流体背景、高性能的 Canvas 渲染以及丰富的歌词特效，极大地提升了用户的听歌体验。

## 2. 主要功能

### 2.1 沉浸式视觉体验
- **Material You 主题**: 自动从当前播放歌曲的封面提取主色调，并应用到整个界面（背景、文字、控件），支持动态调色板。
- **动态背景系统**: 提供多种背景模式：
  - **Fluid (流体)**: 基于 Canvas 和 SVG 滤镜的高性能流体动画，随音乐律动。
  - **Blur (模糊)**: 经典的封面高斯模糊效果。
  - **Gradient (渐变)**: 基于封面提取色的渐变背景。
  - **Solid (纯色)**: 简约的纯色背景。
- **封面美化**: 支持高清封面替换（自动获取大图）、矩形/圆形封面切换、动态阴影效果。

### 2.2 增强型歌词系统
- **逐字歌词 (Karaoke)**: 支持 YRC 逐字歌词解析与渲染，提供 "Float" (上浮) 和 "Slide" (滑动) 等多种动画效果。
- **高光特效**: 歌词播放时带有动态高光扫过效果 (`Lyric Glow`)。
- **多语言支持**: 支持显示原词、翻译、罗马音，并可自由切换。
- **智能滚动**: 包含歌词防遮挡、平滑滚动、间奏跳过等逻辑。
- **歌词编辑/预览**: 提供歌词概览模式 (`Overview Mode`)，方便复制和查看全文。

### 2.3 UI 与交互增强
- **Refined Control Bar**: 重绘底部控制栏，集成 "已播放/剩余时间" 显示。
- **Mini Song Info**: 在页面左下角常驻显示当前歌曲信息（封面、歌名、歌手）。
- **进度条预览**: 鼠标悬停进度条时显示时间点预览。
- **右键菜单增强**: 在封面和歌词区域提供自定义右键菜单，支持复制封面链接、歌词文本等。
- **私人 FM 支持**: 完美适配私人 FM 模式，保持一致的视觉体验。

## 3. 技术栈

- **核心框架**: BetterNCM Plugin API
- **前端库**: React (用于构建 UI 组件), ReactDOM
- **样式预处理**: SCSS
- **图形渲染**: HTML5 Canvas, SVG Filters (用于流体背景)
- **颜色算法**: `@material/material-color-utilities` (Google Material You 算法库), `colorthief`

## 4. 安装与运行

本项目作为 BetterNCM 插件运行，需先安装 BetterNCM。

1. 将项目文件夹放置于 BetterNCM 的 `plugins` 目录下。
2. 启动网易云音乐，在 BetterNCM 插件管理页面启用 "RefinedNowPlaying"。
3. 进入"正在播放"页面即可看到效果。
