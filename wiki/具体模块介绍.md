# 具体模块介绍

> 版本: 2.19.5  
> 最后更新时间: 2025-12-01

本文档详细介绍 Refined Now Playing 的代码结构与各核心模块的功能实现。

## 1. 目录结构概览

```text
src/
├── main.js                  # [核心] 插件入口，负责初始化、全局事件与模块协调
├── manifest.json            # [配置] 插件元数据、注入点定义、API 劫持配置
├── background.js            # [视觉] 动态背景组件 (Fluid, Blur, Gradient)
├── lyrics.js                # [歌词] 歌词渲染核心逻辑 (滚动、动画、交互)
├── lyric-provider.js        # [数据] 歌词数据拦截与处理
├── refined-control-bar.js   # [UI] 底部控制栏增强组件
├── mini-song-info.js        # [UI] 迷你歌曲信息组件
├── context-menu.js          # [交互] 自定义右键菜单
├── utils.js                 # [工具] 通用工具函数库
├── color-utils.js           # [工具] 颜色处理工具
├── compatibility-check.js   # [兼容] 兼容性检查逻辑
└── styles.scss              # [样式] 全局样式文件
```

## 2. 核心模块详解

### 2.1 核心入口 (`main.js`)
**功能**: 插件的大脑，负责生命周期管理和资源调度。
- **初始化**: 通过 `plugin.onLoad` 钩子启动，注入 DOM 监听器。
- **组件挂载**: 监测 `.g-single` (正在播放页) 元素的出现，动态挂载 React 组件 (`Background`, `Lyrics`, `MiniSongInfo`)。
- **主题色提取**: 
  - 函数: `calcAccentColor(dom)`
  - 逻辑: 监听封面图片加载 -> Canvas 读取像素 -> `QuantizerCelebi` 量化 -> `Score` 评分 -> 生成 Material Design 3 色板 -> 设置 CSS 变量 (`--rnp-accent-color-*`)。
- **设置管理**: `initSettings()` 函数负责绑定设置面板的所有 UI 控件到 `localStorage`。

### 2.2 歌词系统 (`lyrics.js` & `lyric-provider.js`)
**功能**: 实现高性能、高可定制的歌词展示。
- **数据层 (`lyric-provider.js`)**:
  - **劫持**: 通过 `manifest.json` 劫持 `orpheus://orpheus/pub/core`，拦截 `onProcessLyrics`。
  - **解析**: 调用 `liblyric` 解析 LRC/YRC 格式，处理歌词元数据（贡献者、翻译者）。
  - **分发**: 通过 `window.dispatchEvent` 发送 `lyrics-updated` 事件。
- **视图层 (`lyrics.js`)**:
  - **同步**: 监听 `audioplayer` 的进度事件，计算 `currentLine`。
  - **滚动**: 实现平滑滚动算法，支持 `lyric-offset` (偏移微调) 和 `lyricStagger` (交错动画)。
  - **渲染**: `Lyrics` 组件维护歌词状态，`Line` 组件负责单行渲染。
  - **特效**: 
    - `Karaoke Animation`: 支持 'float' 和 'slide' 两种逐字动画。
    - `Glow`: 使用 Web Animations API 实现歌词高光扫过效果。

### 2.3 动态背景 (`background.js`)
**功能**: 提供沉浸式背景体验。
- **Fluid Background (流体)**:
  - 技术: HTML5 Canvas + SVG Filters (`feTurbulence`, `feDisplacementMap`)。
  - 逻辑: 将封面图分割绘制到 Canvas，通过 SVG 滤镜产生液化扭曲效果。
  - 交互: 监听音频频谱数据 (如果安装了 `LibFrontendPlay`)，动态调整 `scale` 属性，使背景随低音律动。
- **其他模式**: 包含基于 CSS `filter: blur()` 的模糊模式和 `ColorThief` 提取的渐变模式。

### 2.4 UI 增强模块
- **Refined Control Bar (`refined-control-bar.js`)**:
  - 向底部控制栏注入 DOM，显示精确的"已播放/剩余时间"，解决原版只显示总时长的痛点。
- **Mini Song Info (`mini-song-info.js`)**:
  - 在页面左下角渲染当前歌曲的封面缩略图和元信息，增强视觉层次感。
- **Context Menu (`context-menu.js`)**:
  - 拦截默认右键事件，提供"复制歌词"、"复制封面链接"等实用功能。

## 3. 模块间通信
模块间主要通过 **CustomEvent** 进行解耦通信：
- `lyrics-updated`: 歌词数据更新时触发。
- `recalc-lyrics`: 需要重算歌词高度/位置时触发（如字体大小改变）。
- `rnp-background-type`: 背景模式切换时触发。
- `rnp-accent-color-*`: 主题色更新相关事件。

这种设计使得各模块可以独立开发和测试，降低了耦合度。
